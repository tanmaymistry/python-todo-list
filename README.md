# Python To-Do List 📝

A simple command-line To-Do List application built with Python.

## Features

* Add new tasks
* View all tasks
* Remove tasks
* Saves tasks to a text file
* Loads saved tasks when the program starts
* Handles invalid task numbers and menu choices

## Technologies Used

* Python
* File Handling
* Lists
* Functions
* Exception Handling

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python todo.py
```

## How It Works

The application stores tasks in a `tasks.txt` file.

When the program starts, it loads previously saved tasks. Whenever a task is added or removed, the file is updated automatically.

## Example

```text
===== TO-DO LIST MENU =====
1. View Tasks
2. Add Task
3. Remove Task
4. Exit

Enter your choice (1-4): 2
Enter new task: Study Python
Task added successfully!
```
